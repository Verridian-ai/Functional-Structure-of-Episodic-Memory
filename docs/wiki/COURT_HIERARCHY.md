# Australian Court Hierarchy

## Overview

The Australian court system is organized in a hierarchical structure with 106+ distinct court codes, each assigned an authority score (0-100) based on binding precedent power. This hierarchy determines the weight and precedential value of judicial decisions in the classification system.

---

## Court Hierarchy Levels

### Level System

Australian courts are organized into 8 hierarchical levels:

| Level | Rank | Description | Authority Range |
|-------|------|-------------|-----------------|
| **Apex** | 1 | High Court of Australia only | 100 |
| **Superior Appellate** | 2 | State/Federal appellate courts | 85-90 |
| **Intermediate Appellate** | 3 | Full courts, courts of appeal | 85 |
| **Superior Trial** | 4 | Supreme Courts (single judge) | 70-80 |
| **Intermediate** | 5 | District/County courts | 50-60 |
| **Lower** | 6 | Local/Magistrates courts | 30 |
| **Tribunal** | 7 | Administrative tribunals | 35-60 |
| **Specialist** | 8 | Specialist courts/tribunals | 40-70 |

## Authority Scoring (0-100)

### Scoring Logic

Authority scores determine the precedential weight of decisions:

```python
def get_authority_score(court_code: str) -> int:
    """
    Returns:
        100: High Court (binds all courts)
        85-90: State/Federal appellate courts
        70-80: Supreme Courts
        50-60: District/County courts, specialist tribunals
        30-40: Magistrates courts, general tribunals
    """
```

### Authority Score Examples

| Score | Courts |
|-------|--------|
| **100** | HCA |
| **90** | FCAFC |
| **85** | NSWCA, VSCA, QCA, etc. (all appellate) |
| **80** | FCA |
| **75** | NSWSC, VSC, QSC, etc. (all Supreme) |
| **60-70** | FamCA, specialist courts (LEC, Industrial) |
| **50-55** | District/County courts, FWC |
| **30-40** | Magistrates courts, general tribunals |

## Binding Precedent Logic

### Vertical Binding

Courts are bound by decisions from higher courts in the same hierarchy:

```
HCA (binds all)
  ↓
FCAFC / State CA (binds same jurisdiction)
  ↓
FCA / State SC (binds lower in jurisdiction)
  ↓
District/County (not binding)
  ↓
Magistrates/Tribunals (not binding)
```

### Horizontal Persuasiveness

Courts at the same level provide persuasive (not binding) authority to each other.

**Example**:
- NSW Court of Appeal decision is **persuasive** to Victorian Court of Appeal
- But **binding** on NSW Supreme Court

### Binding Status Determination

```python
class BindingStatus(Enum):
    BINDING = "binding"          # HCA, or higher in same jurisdiction
    PERSUASIVE = "persuasive"    # Same level or other jurisdiction
    NOT_BINDING = "not_binding"  # Lower courts, tribunals
    UNKNOWN = "unknown"
```
